# Aldmere Works

A 10v10 Chivalry 2 Unchained map on an unfinished cathedral building site. Agatha holds the west front and court (blue), the masons the lodge, the east yard and court (red). Camps, smoke, turning crane wheels and site sounds are part of the map.

On its own it plays as Team Deathmatch. With [Aldmere Hardpoint](https://github.com/chivned/AldmereHardpoint) (installed with it as a dependency) it runs the Hardpoint mode; switch "Aldmere Hardpoint" off in the Unchained mods menu for plain Team Deathmatch.

Map name: `TDM_AldmereWorks`.
